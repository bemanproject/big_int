[#api_reference]
= API Reference
:idprefix: api_ref_

[#api_namespaces]
== Namespaces

[cols="1,2", options="header"]
|===
| Namespace | Description
| `beman::big_int` | Contains all components of the library *except* literals and polymorphic memory resource support
| `beman::big_int::literals` | User-defined literals
| `beman::big_int::pmr` | Types with `std::pmr` support
|===

[#api_types]
== Types

[cols="1,2", options="header"]
|===
| Type | Description
| xref:big_int_type.adoc#big_int_type_unit_multi_t[`uint_multiprecision_t`] | The limb type of a `big_int`
| xref:big_int_type.adoc#big_int_type_basic_big_int[`basic_big_int`] | The template of a big integer type. Analogous to `std::basic_string`
| xref:big_int_type.adoc#big_int_type_using_big_int[`big_int`] | A big integer type using default small value optimizations and allocator
| xref:format.adoc#format_synopsis[`std::formatter<basic_big_int>`] | Formatter specialization that plugs a `basic_big_int` into `std::format`
| xref:limits.adoc#limits_synopsis[`std::numeric_limits<basic_big_int>`] | Limits specialization reporting `basic_big_int` as an unbounded, exact, signed integer type
|===

=== Numeric functions

[cols="1,2", options="header"]
|===
| Function | Description
| xref:numeric.adoc#numeric_abs[`abs`] | Returns the absolute value (magnitude) of a `basic_big_int`
| xref:numeric.adoc#numeric_saturating_cast[`saturating_cast`] | Converts a `basic_big_int` to a built-in integer type, clamping to its range
| xref:numeric.adoc#numeric_in_range[`in_range`] | Returns the Boolean result of the range-check if a `basic_big_int` can be represented within the range of another given type
| xref:numeric.adoc#numeric_gcd[`gcd`] | Returns the greatest common divisor of two integers, at least one of them a `basic_big_int`
| xref:numeric.adoc#numeric_lcm[`lcm`] | Returns the least common multiple of two integers, at least one of them a `basic_big_int`
| xref:numeric.adoc#numeric_midpoint[`midpoint`] | Returns half the sum of two integers, at least one of them a `basic_big_int`, rounded toward the first
|===
